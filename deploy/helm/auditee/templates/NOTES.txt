Next steps
----------

1. Verify the API server is healthy:

     kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/component=api
     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "auditee.api.fullname" . }} {{ .Values.api.service.port }}:{{ .Values.api.service.port }}
     curl -sf http://localhost:{{ .Values.api.service.port }}/api/healthz

2. Configure Identity (SSO):

   Set values.identity.saml.metadataUrl OR values.identity.oidc.{issuer,clientId},
   then upgrade the release. Workspace owners can finalise SSO under
   /app/enterprise → SSO tabs.

3. Configure SIEM streaming:

   Set values.siem.{enabled,format,endpoint} and add SIEM_AUTH_HEADER to the
   secret named in values.api.envFromSecret.

4. Customer-managed keys:

   Set values.encryption.{provider,keyRef} and ensure the Auditee service
   account has KMS Encrypt/Decrypt permissions to the key.
